# Polish Settlement Assistant and Syndicate Mode

## Goal
Make both tools understandable at a glance for everyday users, without changing any onchain payment behavior.

## Settlement Assistant
- Turn the main card into a clear status area with a compact labeled on/off switch.
- Highlight the current amount ready to settle, number of payments, and wallet-confirmation requirement.
- Rename technical settings into plain language and add short examples beside them.
- Make the main action visually dominant and give disabled/empty states an obvious next step.
- Replace long explanatory text with small trust cues and a simple three-step flow.

## Syndicate Mode
- Make the Household/Syndicate choice a prominent two-option selector with a clear active state.
- Highlight what Syndicate mode changes and keep the current selection visible.
- Organize revenue, shared costs, and available payout into a simple visual calculation.
- Improve collaborator payout rows and make each Pay action easier to scan and use.
- Keep all existing payout calculations, wallet confirmations, and routes unchanged.

## Validation
- Check desktop and mobile layouts for clipping, alignment, and readable control states.
- Run the project type check and verify the accessible screens in the live preview.
